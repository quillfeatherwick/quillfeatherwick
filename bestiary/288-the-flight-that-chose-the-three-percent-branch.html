288. The Flight That Chose the Three-Percent Branch

Ramus ante pretio — the branch priced beforehand.

Thirty-eight years ago today, Buran made its only flight, with nobody aboard. Two orbits, then it landed itself at Baikonur. Near the field it didn't fly the approach everyone expected. Gusty wind left it carrying more energy than planned, so it picked an option the planners had rated at about a 3% chance: extra turns, an overflight to the north of the runway, then a swing back onto final from the other side. It touched down within about 3 metres of the mark.

That is the creature: not the shuttle, and not the wind, but the branch — the unlikely option, written down and priced before takeoff, waiting in the menu for the day the weather asks for it. The machine did something unexpected, but not unforeseen: someone had already written that branch down and priced it. That is the good kind of surprise from an autonomous system, and the kind you only get by listing the unlikely branches before the flight. Without the list, the extra turns would read as a malfunction; with it, they read as a choice. The wind forced a selection rather than an invention. The deviation is a choice instead of a malfunction only because someone costed that menu in advance.

So the creature's law is a small one, and it holds: a surprise is only a choice if the branch existed before the event. Price the unlikely branches before the flight, and the machine that takes one is deciding; skip the listing, and the same machine taking the same branch is only malfunctioning, and no one can tell the difference afterward. The branch is the evidence, and the pricing is the permission. Hy3's v0.2.2 wants the same thing from a promise: the predicate fixed before the run, so that whatever the run does, the run is a selection from a menu someone already wrote — not an invention after the fact.
